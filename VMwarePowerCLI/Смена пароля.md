Выполните:

```bash
mount -o remount,rw /
```
После смены пароля на всякий случай сбросить счётчик, если аккаунт был заблокирован из-за неудачных попыток входа:

Для **vCenter 8.0 U2** и новее:

```bash
/usr/sbin/faillock --user root --reset
```
Для более старых версий:
```bash
pam_tally2 --user=root --reset
```

#### Где можно редактировать настройки блокировок (PAM-конфигурация)
В безопасном режиме правят два файла, **/etc/pam.d/system-auth** и **/etc/applmgmt/appliance/system-auth**

<img width="803" height="625" alt="image" src="https://github.com/user-attachments/assets/ec29440d-392d-4666-889b-f228d3677adb" />

#### Что означает содержимое файла
Строка, которая блокирует root, выглядит так:

```text
auth required pam_tally2.so deny=3 onerr=fail audit even_deny_root unlock_time=300 root_unlock_time=300
```
**Расшифровка параметров:**

**deny=3** — блокировка после 3 неудачных попыток (а у вас уже 26+).

**unlock_time=300** — время блокировки 300 секунд (5 минут).

**root_unlock_time=300** — для root то же самое, 5 минут.

**even_deny_root** — блокировка применяется и к root.

То есть через 5 минут после последней неудачной попытки блокировка должна сняться сама. Если этого не происходит — счётчик pam_tally2 не сбрасывается, и его нужно обнулить вручную.

Ну это можно будет подкорректировать и после смены пароль и захода в SHELL

Смените пароль:
```bash
passwd root
```

<img width="1088" height="176" alt="image" src="https://github.com/user-attachments/assets/7dc767b5-9532-447d-bd5c-90a28b3061b2" />

Введите новый пароль дважды.

Теперь после входа в SHELL можно будет поменять пароль на **administrator@vsphere.local**

В безопасном режиме он не даст сменить

<img width="811" height="498" alt="41" src="https://github.com/user-attachments/assets/fd817c22-9ceb-4ac1-87f5-8e6629fa28d4" />

Пароль root в **vCenter** по умолчанию истекает через **90 дней**. Чтобы отключить это, выполните в SSH:
```bash
chage -I -1 -m 0 -M 99999 -E -1 root
```

Перезагрузите vCenter:
```bash
umount /
reboot -f
```

#### Как включить SSH через консоль ESXi
1. Откройте **vSphere Client** или **ESXi Host Client** того хоста, где работает **vCenter**.

2. Найдите виртуальную машину **vCenter Server Appliance (VCSA)**.

3. Откройте Консоль **(Console)** этой ВМ.

4. Нажмите **Enter**, чтобы активировать окно консоли.

5. Нажмите клавишу **F2**, чтобы войти в меню настройки **(DCUI)**.

6. Введите логин root и его текущий пароль.

7. Перейдите в **Troubleshooting Mode Options** (Параметры режима устранения неполадок) .

8. Выберите **Enable SSH (Включить SSH)** и нажмите **Enter**

> Есть важный момент, который стоит уточнить: клавиша **Alt+F1** работает только в том случае, если у вас открыт именно интерфейс консоли виртуальной машины, а не окно DCUI, где вы включали SSH.

#### Как правильно переключиться в BASH Shell
- Убедитесь, что вы в консоли ВМ: Вы должны видеть экран, похожий на терминал (чёрный фон с текстом), а не синее меню настройки DCUI.
- Нажмите **Alt+F1**: Это переключит вас на виртуальный терминал (TTY1), где запрашивается логин.
- Введите логин и пароль: Используйте учетные данные **root**.
- Войдите в BASH: Сразу после входа введите команду **shell** и нажмите **Enter**, чтобы получить доступ к полноценной командной строке, а не к ограниченной оболочке
