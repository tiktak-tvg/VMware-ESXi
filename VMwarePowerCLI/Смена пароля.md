### Как менять пароли через GRUB на виртуальной машине vCenter.

<img width="1088" height="406" alt="image" src="https://github.com/user-attachments/assets/51d72012-234c-4989-b647-29cfa780a44f" />

Потребуется доступ к консоли виртуальной машины vCenter.

#### 1. Перезагрузите VCSA.

<img width="1080" height="587" alt="image" src="https://github.com/user-attachments/assets/3b030451-11fa-4b03-80d9-7a251f689bf7" />

#### 2. В меню загрузки Photon OS нажмите e.

#### 3. Найдите строку, начинающуюся с linux, и в конце допишите: rw init=/bin/bash.

<img width="1085" height="616" alt="image" src="https://github.com/user-attachments/assets/bf047d31-9df0-42dd-91fc-2c1c01eb6f35" />

#### 4. Нажмите F10 для загрузки.

<img width="1160" height="372" alt="image" src="https://github.com/user-attachments/assets/2f160761-abf9-42a4-93d0-c2bd21671d5b" />

Выполните:

```bash
mount -o remount,rw /
```
После смены пароля на всякий случай сбросить счётчик, если аккаунт был заблокирован из-за неудачных попыток входа:

Для vCenter 8.0 U2 и новее:

```bash
/usr/sbin/faillock --user root --reset
```
Для более старых версий:
```bash
pam_tally2 --user=root --reset
```

<img width="1160" height="691" alt="image" src="https://github.com/user-attachments/assets/e376f322-95e7-4fdc-b90b-00e4484671dd" />

Смените пароль:
```bash
passwd root
```

<img width="1088" height="176" alt="image" src="https://github.com/user-attachments/assets/7dc767b5-9532-447d-bd5c-90a28b3061b2" />

Введите новый пароль дважды.

Теперь после входа в SHELL можно будет поменять пароль на administrator@vsphere.local

В безопасном режиме он не даст сменить

<img width="811" height="498" alt="41" src="https://github.com/user-attachments/assets/fd817c22-9ceb-4ac1-87f5-8e6629fa28d4" />

Пароль root в vCenter по умолчанию истекает через 90 дней. Чтобы отключить это, выполните в SSH:
```bash
chage -I -1 -m 0 -M 99999 -E -1 root
```
```bash
umount /
```
Перезагрузите: 
```bash
reboot -f
```

#### Как включить SSH через консоль ESXi
1. Откройте vSphere Client или ESXi Host Client того хоста, где работает vCenter.

2. Найдите виртуальную машину vCenter Server Appliance (VCSA).

3. Откройте Консоль (Console) этой ВМ.

4. Нажмите Enter, чтобы активировать окно консоли.

5. Нажмите клавишу F2, чтобы войти в меню настройки (DCUI).

6. Введите логин root и его текущий пароль.

7. Перейдите в Troubleshooting Mode Options (Параметры режима устранения неполадок) .

8. Выберите Enable SSH (Включить SSH) и нажмите Enter
